INSTRUKSI ICON PWA E-ASFARM
============================

Silakan tambahkan 3 file icon berikut di folder ini:

1. icon-152x152.png  (untuk iOS)
2. icon-192x192.png  (untuk Android xxhdpi)
3. icon-512x512.png  (untuk Android splash screen)

Format: PNG dengan background
Sumber: Logo E-Asfarm yang sudah ada

Cara membuat:
- Gunakan logo E-Asfarm-Logo.png yang sudah ada
- Resize ke 3 ukuran di atas
- Pastikan ada background (tidak transparan)
- Simpan sebagai PNG

Tools online yang bisa digunakan:
- https://www.iloveimg.com/resize-image
- https://www.photopea.com (online photoshop)
- https://realfavicongenerator.net (auto generate semua ukuran)

Setelah icon ditambahkan, PWA siap digunakan!
